# Character reference

Establish and reuse a character reference when the same person must appear across generated images or shots. Reuse an already approved reference. A one-off image without a continuity requirement does not need an additional sheet.

## Three-panel sheet

Use the uploaded photo to generate a large frontal face portrait, a front body view cropped from the neck down to the shoes, and a complete rear view including the back of the head. This is one reference layout; add a profile, expression, or pose when the intended performance needs it.

## Generation prompt

Create a three-panel character reference sheet based on the uploaded photograph. This sheet will guide consistent character appearance across later image and video generations.

REFERENCE
Use the uploaded photograph as the identity reference. Preserve the person's recognizable facial features, facial proportions, skin tone, hairstyle, hairline, build, and visible clothing and accessories. Follow any clothing changes requested by the user.

LAYOUT
Create one wide image with three clearly separated vertical panels:

LEFT — FACE REFERENCE
A large, front-facing head-and-shoulders portrait with a relaxed, neutral expression. Show the entire head and hairstyle clearly. Give the face enough space to preserve fine identity details. This is the only panel showing the face.

CENTER — FRONT BODY REFERENCE
A front-facing standing view framed from the base of the neck down to the soles of the shoes. The head is outside the crop; this is a clothing and body reference, not a depiction of injury. Show the complete outfit, body proportions, hands, accessories, and footwear clearly. Arms rest naturally with enough separation to reveal the clothing.

RIGHT — BACK REFERENCE
A complete rear view of the same person, including the entire head, back of the hair, body, and shoes. Face directly away from the camera. Show the back of the outfit and hairstyle clearly.

CONSISTENCY
All three panels depict the same person, hairstyle, body proportions, outfit, and accessories. Keep garment colors, construction, fit, and accessory placement consistent between front and back.

Use a plain neutral background and even, soft lighting. Keep the panels separate, with no overlapping figures. Show only the three requested views, without additional portraits, inset images, text, labels, or watermarks.

MISSING DETAILS
Preserve details visible in the uploaded photograph. Where the photograph does not show the body, footwear, or back of the outfit, complete those areas simply and coherently with the visible appearance and any clothing instructions supplied by the user.

## Confirm and reuse

Show the sheet to the user to confirm likeness, build, clothing, accessories, and any inferred details absent from the original photo. Revise from their feedback, then save the approved reference for subsequent generation. Retain the uploaded photo as the identity authority when correcting likeness.

Combine the reference with each shot's setting, composition, and action. Use a character-reference input where supported. When an actual first frame is required, first create a single shot image from the reference, then animate that image.
