# Remaking what is in the picture

How to make a picture or clip again once the request is a change to what is in it. Find the element at that moment first: the app's context names any generated video there and its recipe in `.hyperframes/heygen-recipes`; when it names none, read the composition and find the element shown at that second by its `data-start` and `data-duration`. Say in one line which element and time it is and what the new prompt adds, then make it, and say plainly what you made. Paid calls run with no approval step.

## Match the media kind

| What is there                                                                | How to remake it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| An `<img>` or image file (`.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.avif`) | `image.generate`, never `video.generate`: the current image as its only reference, a prompt describing the picture as it is plus the change, the `aspect_ratio` nearest its own (`nano-banana-2` has the most shapes). Point the element's `src` at the new file                                                                                                                                                                                                                                    |
| A `<video>` that is really a still (ffprobe shows one frame, or no motion)   | The same, from a frame extracted with ffmpeg; show it as an `<img>` with the same `data-start` and `data-duration`                                                                                                                                                                                                                                                                                                                                                                                  |
| A single generated clip (recipe kind `"clip"`)                               | `video.generate` with the recipe body's prompt plus the change, its `seed`, and its `duration`, `resolution`, `aspect_ratio` and `prompt_enhancement` as they are. A body `image` (first frame, base64) goes to a file under `assets/` passed as `first_frame`; each `reference_images` entry the same way (`.png`, `.jpg` or `.webp` per its `media_type`), passed in order as `references`. Point the old clip's `src` at the new file, keeping its `data-start`, `data-duration` and media start |
| A video with no recipe (uploaded or imported)                                | Extract its first shown frame (at `data-media-start` or `data-playback-start`, else 0) to a `.jpg` under `assets/` and pass it as `first_frame`. Prompt: the scene, people, motion and camera as seen in its frames, plus the change. `duration`: its shown seconds rounded up, at least 5. Point `src` at the new file, keep `data-start` and `data-duration`, set the media start to 0                                                                                                            |
| A clip whose recipe has `reference_audio` (a spoken line)                    | No tool can remake it with that voice yet. Remake it from the recipe without `reference_audio`, mute the new clip and play the old file's audio over the same seconds, and say the voice is the original's and the lips may not follow it                                                                                                                                                                                                                                                           |
| One piece of a joined clip (recipe kind `"joined"`)                          | No tool can regenerate a piece and join it back yet. Remake the piece as a separate clip from its own recipe, place it on a track above the joined clip over the piece's seconds, and say it sits over the joined clip, not inside it                                                                                                                                                                                                                                                               |

Extracting one frame with ffmpeg is fine; never join or cut pieces yourself with ffmpeg.
